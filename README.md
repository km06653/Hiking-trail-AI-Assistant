# Hiking-trail-AI-Assistant
An AI-powered hiking assistant using Google's Gemini API
## Frontend Contributions

[Aidan Perez](https://github.com/aidanperez012-AP) built the React
frontend and connected it to the team's backend APIs. Contributions
